# AEGIS Capture - Windows

Screen region capture for MT5. Sends PNGs to AEGIS Cloud every 3s.

## Features
- Captures specific screen region, not full desktop
- Sends frames to AEGIS Cloud API
- Includes AEGIS_Executor.mq5 for MT5
